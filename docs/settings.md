# 应用设置

主页仅显示“设置”入口。设置页分为处理与速度、识别与翻译、擦字与修复、字体与排版、输出与存储。

设置自动保存到 `%APPDATA%\MangaTrans\settings.json`。环境变量 `MANGATRANS_SETTINGS` 可指定其他路径。任务使用启动时的配置快照，运行期间不能修改设置。设置无法读取时会显示错误，不会直接覆盖原文件。

## 数值参数

界面直接显示数值。当前值等于默认值时，数值后显示“默认”。

| 参数 | 默认值 | 范围与含义 |
| --- | --- | --- |
| 翻译批次页数 | 2 | 1～4，连续页共享批次的上限，不是完整上下文记忆 |
| 检测置信度阈值 | 0.35 | 0.05～0.95，降低可能增加检出与误检 |
| 检测补充分块 | 0 px | 0 关闭补检，256～4096 指定原图分块大小 |
| 批量翻译最大尝试次数 | 2 | 1～5，包含首次请求，之后缺失译文仍有单独补译 |
| 擦字扩展 | 6 px | 0～24，扩大可能减少残字，也可能擦除邻近线稿 |
| 修复上下文 | 64 px | 16～256，背景修复参考范围 |
| 修复分块尺寸 | 0 px | 0 按连通区域处理，128～2048 指定原图窗口大小 |
| 字号倍率 | 1 | 0.7～1.4，仍受气泡边界约束 |
| 最小字号 | 0 pt | 0 自动，最大 72，空间不足时仍须遵守边界 |
| 行列间距倍率 | 1 | 0.5～2 |
| 描边宽度 | -1 px | -1 自动，0 关闭，正数最大 4 |
| JPEG 质量 | 92 | 80～100 |
| WebP 有损质量 | 90 | 1～100，与 JPEG 的同值质量不能直接比较 |
| 输出长边上限 | 0 px | 0 保持原尺寸，640～16383 只缩小不放大 |

分块大小不是 ONNX 模型的输入尺寸。检测模型和修复模型仍使用各自的固定张量尺寸。增大数值不保证提高质量或速度。

## 排版与图片格式

文字方向可选竖排、横排、自动。字体可选择 TTF、OTF、TTC 文件。文字颜色支持 `auto` 或 `#RRGGBB`。

输入仍为 CBZ 或 ZIP。归档内可包含静态 WebP 页面。输出仍为 CBZ，页面可保存为 JPEG、PNG、WebP。

PNG 和 WebP 无损保存不引入新的有损编码失真，但不能恢复原图已经丢失的细节。选择 WebP 无损后，不显示有损质量参数。

“无文字页面保留原图”开启时，这些页面保留原始格式、尺寸和字节。关闭后按输出设置转换。处理失败的页面始终保留原图，因此输出漫画包可能包含多种图片格式。

## 验证限制

`go run ./cmd/verify-settings` 检查配置读写、校验、版本迁移和失败保护，报告写入 `.cache/settings/config-verification/report.json`。

`go run ./cmd/verify-pageimage` 检查图片编解码和归档回读，报告写入 `.cache/settings/codec-report.json`。这些命令不代表完整翻译流水线已经通过验证。

当前主机曾对 Go 生成的 `translate.test.exe` 报警。在告警解决前，不运行 `go test`，不恢复隔离文件，不添加杀毒排除项。自动验证不启动、聚焦或操作桌面窗口。
